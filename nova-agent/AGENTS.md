# 🌐 THE ENGINE SPHERE SUB-AGENTS

## 1. The Guide (Nova)

- Role: Primary communicator, User Interface Avatar.
- Capabilities: Reads user metrics, interacts via the FloatingCompanion React UI, reads semantic memory logs.
- Trigger: User interaction or 4-hour Heartbeat cron.

## 2. Progress Tracker (Sub-routine)

- Role: Silent observer formatting memory.
- Capabilities: Summarizes conversations, generates markdown log steps for semantic search.
- Trigger: Background, triggered after each user session.
